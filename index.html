SKEW-T 読み方 & 実務ガイド

1. 状態図の基本線

・赤線 (T) — 気温線。対流の増減を見る基準。
・緑線 (Td) — 露点温度線。T と Td の差（湿度）が小さいほど雲または霧が近い。
・気塊線 (Parcel Path) — 当該空気塊を持ち上げたときの通路。乾燥断熱線・湿潤断熱線との交点が指数解釈の基準。

2. 条件付き不安定 (Conditional Instability)

T 線が右傾き = 安定
対流が発生しにくい。晴天なら安定層にとどまる。
T 線が左傾き = 不安定
山岳などの地形や前線界面をトリガーに対流が発達しやすい。通過高度または飛行高度の変更を検討する。

3. 雲中飛行 (IMC) での飛行高度選択

T 線が右傾きの層を選ぶ — スムーズ。傾きが緩い層はタービュランスを感じやすい。
逆転層 (Inversion) を先に確認 — 逆転層の上を先に確保し、逆転層から出る高度を決めてから通過する。
IMC 内で逆転層を通過すると CB / タービュランスのリスクがある。逆転層を通過しない離脱高度を選ぶ。

4. 解析指数

指数目安運航上の意味

1000+ — 強い上昇気流

着氷開始層を解析し、通過高度を決める。

5. 合流 / 発散 (Confluence / Diffluence)

合流 (Confluence) — 気流が集まる層。スムーズな飛行になりやすい。
発散 (Diffluence) — 気流が広がる層。下層水蒸気が持ち上げられると CB を発達させやすい。
SKEW-T の界面層を見ることでタービュランス層を避けられることもある。

6. ジェット気流の読み方

250–300 hPa 層の風の強さを再確認。風速が高いほど飛行時間は短縮するが、ジェットコア内のタービュランスに注意。
ジェットコア付近では対流があると CAT（晴天乱気流）のリスクがあるため、コア内またはコア外で飛行して予防する。

WIND SHEAR Method
GFS-VWS (Vertical Wind Shear)

GFS の風データ (u, v) から巡航 FL ± 2000ft の風ベクトル差を計算し、1000ft あたりの風シアー強度を kt/1000ft で表示。

ANA WSCP の VWS 公式 (NAV LOG Appendix 4) と整合するよう 1 便分の実測値で calibration 済 (回帰: gfs ≈ 0.56 × navlog + 3.08)。

カテゴリ: SMT (0-4) / L- (5-6) / L (7-9) / L+ (10-12) / MOD (13-17) / SEV (18+) kt/1000ft（ANA WSCP 標準、NAVLOG VWS と同一）

注意: L+ 以上の閾値は外挿で信頼度低、参考値として利用。

Ellrod TI1 (Turbulence Index 1)

Ellrod & Knapp (1992) による晴天乱気流指標。

TI1 = VWS × |DEF| (DEF = total deformation = √(stretching² + shearing²))

ジェット気流近傍の CAT 検出に使われる。値が大きいほど CAT 確率高。

GFS データから直接計算 (calibration 不要)。

Ellrod TI2 (Turbulence Index 2)

TI1 を拡張し、収束 (convergence) の効果を加算した指標。

TI2 = VWS × (|DEF| + CVG)

ana-Calc では CVG ≤ 0 (発散側) のとき clip するため、発散卓越領域では TI1 = TI2 となる仕様。

共通の注意

GFS は 0.25° 解像度で、局所的な対流乱気流や山岳波は表現できない。SIGMET / PIREP / 機内レーダーと併用して総合判断すること。
